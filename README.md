Solving [cryptopals challenges](https://cryptopals.com/) for fun a profit. Well, not profit, but learning.

Each challenge has a runnable script (organized by set) that illustrates the solution, eg

```shell
uv run python challenges/set01/c06_break_repeating_xor.py
```

Diagnostics with

```shell
uv run pytest
uv run ruff check [--fix]
```
